# Telegram Bot: Radio Station Playlist Generator

⚠️ **Важное примечание:** Для стабильной работы данного Telegram-бота на территории России необходим VPN (или настроенный прокси) для обхода блокировок серверов Telegram со стороны Роскомнадзора.

## Описание функционала
Данный Telegram-бот предназначен для быстрого поиска интернет-радиостанций и автоматической генерации плейлистов в формате `.m3u`. Полученные плейлисты можно использовать в любом поддерживающем этот формат медиаплеере (VLC, AIMP, Winamp и др.).

Бот использует открытое API **Radio Browser** для поиска радиостанций по всему миру. 

**Основные возможности:**
- **Интеллектуальный поиск:** Бот принимает любое текстовое сообщение от пользователя и ищет совпадения сразу по трем направлениям:
  1. Название радиостанции (name).
  2. Жанр или тег (tag).
  3. Страна (country).
- **Отсеивание дубликатов:** Результаты поиска фильтруются по уникальному идентификатору станции (`stationuuid`), благодаря чему в итоговом плейлисте не будет повторяющихся записей.
- **Динамическая генерация файлов:** Бот автоматически создает файл вида `playlist_<запрос>.m3u`, записывает туда адреса потоков (`#EXTINF` и `url_resolved`), отправляет файл пользователю как документ и затем безопасно удаляет временный файл с сервера.
- **Индикация процесса:** Бот информирует пользователя о начале поиска и количестве найденных станций, заменяя первоначальное сообщение.
- **Безопасная конфигурация:** Токен бота не "зашит" в код, а вынесен в отдельный файл `config.ini`, что предотвращает его случайную утечку при публикации кода на GitHub.

## Требования и зависимости
Для запуска бота потребуется **Python версии 3.7 или выше**.

**Необходимые сторонние библиотеки:**
- `pyTelegramBotAPI` (импортируется в коде как `telebot`) — фреймворк для взаимодействия с Telegram API.
- `requests` — библиотека для выполнения HTTP-запросов к Radio Browser API.

*Остальные используемые модули (`os`, `sys`, `configparser`) являются встроенными библиотеками Python и не требуют дополнительной установки.*
